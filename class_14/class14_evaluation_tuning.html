Why tune

Tuning = finding the sweet spot.

Grid search

Try every combination. Keep the CV winner.

R · caret
grid <- expand.grid(cp = seq(0.001, 0.1, 0.005)) fit <- train(diabetes ~ ., data = train, method = "rpart", trControl = ctrl, metric = "ROC", tuneGrid = grid)
plot(fit)

0.81 → 0.85 — same data, better dial.
