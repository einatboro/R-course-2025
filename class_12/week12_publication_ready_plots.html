PART 01

The Publication
Standard

What separates a default ggplot from a figure that ships in a journal.
25 minutes
Side by side

Same data. Two worlds.

Default ggplot()

Gray panel · multiple colors · gridlines everywhere

Publication ready

White panel · single color · meaningful axes · units
Four shifts that did the work
01 · TYPOGRAPHY

One font, sized to read

Helvetica or Arial, sized so axis labels survive at 80% page width.

02 · CLEAN CHROME

Less ink, more signal

No gray panel. No gridlines that compete with the data.

03 · RESOLUTION

300 DPI vector when possible

The figure must hold up when printed at column width.

04 · EYE PATH

Reader's eye lands where the story is

Color used as emphasis, not decoration. The reader knows in two seconds what the figure is saying.

SECTION 02 · TECHNICAL REQUIREMENTS

Journals have rules. The figure either passes the check, or it bounces back.

File formats

Vector vs. Raster

FormatTypeUse it for
PDFVectorDefault submission. Scales to any size, no quality loss.
SVGVectorWeb, slides, post-processing in Illustrator or Inkscape.
PNGRasterPlots that include photos or rendered images.
TIFFRasterRequired by some journals (Cell, Nature) for final figures.
JPEGRasterNever. Lossy compression smears thin lines and text.
300
Dots per inch.
The minimum for any figure that gets printed. Below 300 DPI, edges blur and small text becomes unreadable on paper.
Size before you save

Plan the figure for the column it will live in.

SINGLE COLUMN

~3.5 in / 89 mm

Default for most life-science journals. Plan text to remain readable here.

DOUBLE COLUMN

~7.0 in / 180 mm

Wide figures, multi-panel composites, dashboards.

FULL PAGE

~7.0 × 9.5 in

For complex multi-panel figures. Used sparingly.

Labels — small detail, big credibility

Units belong in parentheses.

Sentence case for axis titles. The unit comes in parentheses, separated by a space.

# Wrong labs(y = "GLUCOSE") labs(y = "glucose mg/dl") # Right labs(y = "Glucose (mg/dL)") labs(y = "BMI (kg/m²)") labs(y = "Age (years)")
Legend

Put the legend inside the plot when there's room.

A legend outside the panel steals horizontal space — and that space is exactly what your data needs to breathe. If empty area exists in a corner, the legend goes there.

theme(legend.position = c(0.85, 0.85), legend.background = element_rect(fill = "white"))

Advanced
R Toolbox

theme(), ggpubr, patchwork — the three layers that turn ggplot into journal output.
35 minutes
THEME()

Every detail you don't like in a default plot lives inside theme().

Four arguments do most of the work
my_theme <- theme_minimal(base_size = 12) + theme( axis.line = element_line(color = "black", linewidth = 0.4), # clean axes panel.grid = element_blank(), # kill the grid text = element_text(family = "Helvetica"), # one font everywhere strip.background = element_rect(fill = "grey90", color = NA) # facet headers )

Save it once, reuse it on every figure in the paper.

Statistical annotations

Significance stars without the spreadsheet.

library(ggpubr) ggboxplot(df, x = "diabetes", y = "glucose", fill = "diabetes") + stat_compare_means( method = "wilcox.test", label = "p.signif" )

Adds:

  • ★
    p-value or significance stars
  • ★
    bracket lines between groups
  • ★
    your choice of test
Multi-panel figures

patchwork — combine plots with + and /

No more grid.arrange gymnastics. Three operators is all you need.

library(patchwork) # Side by side p1 + p2 # Stacked p1 / p2 # A on top, B and C below p1 / (p2 + p3)
A
histogram
B
boxplot
C
bar chart
One legend. One title. Auto-tags.
(p1 / (p2 + p3)) + plot_annotation( title = "Figure 1. Glucose, BMI, and Outcome", tag_levels = "A" # A, B, C labels added automatically ) + plot_layout(guides = "collect") # merge identical legends

Project

Build one PDF dashboard with three coordinated plots that tell a research story.

THE MISSION

Build a 3-panel dashboard that tells one story.

Use the palmerpenguins dataset. Output one PDF, three coordinated plots, all sharing the same color palette and theme. Every label complete, every axis with units, ready to drop into a manuscript.

palmerpenguins ggplot2 ggpubr patchwork PDF · 300 DPI
STEP 01 · Distribution

The histogram

Show the distribution of one continuous variable. Justify your binwidth. Overlay a density curve.

  • ·
    justified binwidth
  • ·
    density overlay
  • ·
    theme_pubr()
ggplot(penguins, aes(x = flipper_length_mm)) + geom_histogram(aes(y = after_stat(density)), binwidth = 3, fill = "#22d3ee", color = "white") + geom_density(linewidth = 0.8) + labs(x = "Flipper length (mm)", y = "Density") + theme_pubr()
STEP 02 · Comparison

The boxplot

Compare the same variable across groups. Show the raw points and the test result.

  • ·
    geom_jitter with low alpha
  • ·
    outliers hidden in box (shown by jitter)
  • ·
    stat_compare_means
ggplot(penguins, aes(species, body_mass_g, fill = species)) + geom_boxplot(alpha = 0.5, outlier.shape = NA) + geom_jitter(width = 0.15, alpha = 0.4, size = 1) + stat_compare_means(method = "kruskal.test") + labs(x = NULL, y = "Body mass (g)") + theme_pubr() + theme(legend.position = "none")
STEP 03 · Summary

The bar chart

Counts or means, ordered by value. Value labels above the bars. Drop the legend if the x-axis already names the groups.

  • ·
    fct_reorder for ordering
  • ·
    geom_text for value labels
  • ·
    no redundant legend
penguins |> count(species) |> ggplot(aes(fct_reorder(species, n), n, fill = species)) + geom_col() + geom_text(aes(label = n), vjust = -0.5) + labs(x = NULL, y = "Number of birds") + theme_pubr() + theme(legend.position = "none")
STEP 04 · Final assembly

Combine and export

# Layout: histogram on top, boxplot and barchart below final <- p_hist / (p_box + p_bar) + plot_annotation(tag_levels = "A") + plot_layout(guides = "collect") # Save at exact print size, 300 DPI, vector PDF ggsave("figure_1.pdf", plot = final, width = 7, # inches — double-column height = 5, dpi = 300, device = cairo_pdf)
PART 04 · Peer review checklist

Final QA before submission

Is every text element readable without zooming?Open the PDF at 100%. If you squint, increase base_size.
Does every axis have a label and units?"Time" is wrong. "Time (hours)" is right.
Are colors consistent across all three panels?Same factor → same color, in every plot.
Does the figure survive black-and-white printing?Print one. Or convert to grayscale and look again.
Are panel tags (A, B, C) present and consistent?Reviewers will reference them in comments.
Saved as PDF (or TIFF) at 300 DPI, exact size?No screenshots. No JPEGs.
